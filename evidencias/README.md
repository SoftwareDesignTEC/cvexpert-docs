# Evidencias de validación

El [estado de entrega](../docs/estado-entrega.md) registra los resultados reproducidos y su alcance. Para añadir una ejecución, indique fecha, revisión, entorno, operaciones, códigos, número de aserciones y omisiones. Use la salida resumida del [runner Newman](../postman/README.md).

Conserve los reportes completos en almacenamiento privado. Al compartir una evidencia, elimine tokens de autorización, tokens de dispositivo, correos, cuerpos con datos privados, identificadores de cuentas, certificados y cadenas de conexión.
